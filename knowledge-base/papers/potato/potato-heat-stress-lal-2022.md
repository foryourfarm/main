## 8단계 정리

### 1. 데이터 수집 방법
리뷰 논문. 선행 연구 인용 (Obiero: 30°C vs 22°C, Fleisher 광합성, Tang 다품종)

### 2. 표본/전처리
원문 실험 없음. 인용 논문별로 상이 (N 미명시)

### 3. 메커니즘
- ROS 축적 → 막손상 → PSII 효율 감소 → 광합성 억제
- RuBisCo activase 열변성
- 소스-싱크 이동 교란
- Gibberellin 증가 → 괴경형성 지연

### 4. 정량적 결과 ⭐

| 지표 | 수치 |
|------|------|
| 부작용 시작 | >22°C |
| 광합성 감소 | 25%/5°C (30°C 기준) |
| 괴경 크기 감소 | 45% (30°C vs 22°C) |
| 엽면적 감소 | 35% |
| 춘작 수확량 손실 | 68% (아열대) |
| 추작 수확량 손실 | 42% (아열대) |

### 5. 산업 적용
- 파종 시기 조정 (LINTUL/DSSAT 모델)
- 멀칭, 점적관수
- 조기숙성 품종 선발
- Wild species HSP 강화

### 6. 한계
- 원문 실험 없음
- 인용 논문 간 온도/기간/품종 불일치
- 복합응력(고온+건조) 분리 연구 미흡
- 다배체 복잡성

### 7. 구조적 문제
리뷰 특성상 수치 신뢰도 근거 미약

### 8. 새로운 Gap
- 한국 품종별 임계값
- 토양 조건별 반응
- 부위별 냉해(잎만 -3°C, 괴경 미정)
