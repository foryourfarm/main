## 1. 데이터 수집

### 1.1 협회 안내서 범위

- **대상**: 농가·비료 판매자 및 관련 기관
- **목적**: RDA 표준과 업계 관행의 조화, 합리적 시비 기준 제시
- **섹션**:
  1. 작물별 비료 선택 가이드 (과수 전용)
  2. **사과 인산질비료 시비 기준**
  3. 비료 유형별 특성 (용성인비, 과인산석회, 복합비료 등)
  4. 시비 시기·방법 (실무)
  5. 주의사항 (토양 조건별)

### 1.2 수집 항목

- 과수(사과)의 권장 인산질비료 시용량
- RDA 기준과의 비교·조화점
- 실제 농가 관행과의 격차
- 비료별 P₂O₅ 함량 기준

## 2. 데이터 전처리 및 초기값

### 2.1 P2O5 표시 기준

**협회 기준 = RDA 준용**:
- **분석법**: Bray-1 (RDA 표준)
- **토양 등급 기준**: RDA와 동일
  - 부족: < 30 mg/kg
  - 적정: 30~50 mg/kg
  - 과잉: > 50 mg/kg

**업계 표준 비료 성분 표시**:
- 용성인비 (0-46-0): 46% P₂O₅
- 과인산석회 (0-20-0): 20% P₂O₅
- 복합비료 예시 (12-8-8): 8% P₂O₅
- 다목적비료 (15-15-15): 15% P₂O₅

### 2.2 초기값 (협회 기본 위치)

**협회의 입장**:
- RDA 처방을 기본값으로 인정
- 단, **실제 농가 상황을 반영하자** → 처방보다 다소 높은 실용 기준 제시
- 목표: "과학적이면서도 현실적인" 기준

| 토양 P (mg/kg) | RDA 처방 (kg/10a) | 협회 실무 권장 (kg/10a) | 차이 |
|---|---|---|---|
| < 30 | 8~10 | 10~12 | +20~25% |
| 30~50 | 4~5 | 6~8 | +50% |
| > 50 | 0 | 0~2 | 극소량 |

## 3. 로직

### 3.1 협회 시비 설계의 원칙

**협회의 관점**:
1. **RDA는 표준**, 협회는 "표준 + 현실성" 사이 조정역
2. **상품화 관점**: 비료 업체 이익도 고려하되(과다 권유 금지), 농가 수익성 우선
3. **지역·기후 차이**: 강수량이 많은 지역은 인산 손실이 커서 RDA보다 높여야 함
4. **서방성 고려**: 최신 비료 기술(코팅·서방성 비료)을 반영한 효율 상향

### 3.2 변수

**독립 변수**:
- 토양 유효인산 (mg/kg, Bray)
- 강수 패턴 (연간 강수량)
- 비료 유형 (용성 vs 서방성 vs 복합)
- 지역 (강수량·토양 특성)

**종속 변수**:
- 권장 P₂O₅ 시용량 (kg/10a)
- 선택 비료 상품

## 4. 결과

### 4.1 사과 인산질비료 시비 기준 (협회 안내)

**Table 1: 토양 검정 기반 사과 인산 시비 기준**

| 토양 유효인산 (mg/kg) | 등급 | 협회 권장 (kg P₂O₅/10a) | RDA 기준 | 차이 | 사용 비료 예시 |
|---|---|---|---|---|---|
| < 25 | **매우 부족** | 12~14 | 8~10 | ↑ 40~50% | 과인산석회 70kg + 용성인비 30kg |
| 25~30 | **부족** | 10~12 | 8~10 | ↑ 20~25% | 과인산석회 60kg |
| 30~40 | **중간 부족** | 6~8 | 4~5 | ↑ 50% | 용성인비 20~30kg 또는 복합비료 |
| 40~50 | **적정** | 3~4 | 4~5 | ↓ 15% | 복합비료(혼용) 또는 생략 |
| > 50 | **과잉** | 0 (생략) | 0 | 동일 | 시비 중단 권장 |

### 4.2 지역별 강수량 보정

**협회의 추가 가이드**:

| 지역 강수 패턴 | 보정 계수 | 실제 예 |
|---|---|---|
| **다우 지역** (연 1,500mm 초과) | +1.2 | 전남 호남, 강원 영동 → RDA × 1.2 시비 |
| **평년** (연 1,200~1,500mm) | 1.0 | 경기, 충청 → RDA 표준 |
| **소우 지역** (연 1,000mm 미만) | 0.9 | 경북 내륙 → RDA × 0.9 |

**근거**: 강수가 많으면 토양 P 용탈 손실 크므로 여유 있게 시비.

### 4.3 비료별 선택 기준

**협회 권장 비료 조합**:

| 토양 P 상태 | 1차 비료 | 2차 비료 (보조) | 시기 |
|---|---|---|---|
| 매우 부족 (< 25) | **과인산석회** (20% P₂O₅, 천천히 작용) | 용성인비 (빠른 효과) | 가을(과인산) + 봄(용성) |
| 부족 (25~30) | **과인산석회** | — | 가을 |
| 중간 부족 (30~40) | **복합비료** (12-8-8 등) | — | 가을 또는 봄 |
| 적정 (40~50) | 복합비료 또는 **생략** | — | 필요시만 |
| 과잉 (> 50) | **생략** | — | — |

### 4.4 시비 시기 (협회 실무)

| 시기 | 양 | 비료 유형 | 이유 |
|---|---|---|---|
| **기본(9월~10월)** | 전량 | 과인산석회 또는 복합비료 | 가을, 다음해 꽃눈 분화 기간 |
| **추가(4월~5월)** | 30~50% | 용성인비 또는 엽면살포 | 개화 전 신속 공급 필요시 |

## 5. RDA와의 비교 분석

### 5.1 일치점

| 항목 | RDA | 협회 | 평가 |
|---|---|---|---|
| 추출법 | Bray-1 | Bray-1 | ✓ 동일 |
| 등급 경계 | < 30 부족, 30~50 적정 | 동일 | ✓ 동일 |
| 기본 시비 시기 | 9월~10월 | 9월~10월 | ✓ 동일 |
| 비료 유형 | 용성인비, 과인산석회 등 | 동일 | ✓ 동일 |

### 5.2 불일치점 (협회가 상향)

| 항목 | RDA | 협회 | 차이 | 근거 |
|---|---|---|---|---|
| 전체 시용량 | 8~10 (부족 시) | 10~12 | +20~25% | 강수·토양 변동성 고려 |
| 적정 구간 시비 | 4~5 | 6~8 | +50% | "여유 있는 관행" 인정 |
| 강수량 보정 | 미언급 | ±20% | 신규 | 강수 다우지역 대응 |

**해석**: 협회는 RDA를 기본으로 하되, **현장의 편차(강수·토양 이질성)를 수용**한 더 높은 기준 제시 → 농가 실패율 감소 목표.

## 6. 활용 방안

### 6.1 이론 vs 실무 이중 기준 도입

```
crop_growth_guide에 두 가지 처방 병기:

1. 과학적 기준 (RDA):
   p2o5_optimal_min: 30
   p2o5_optimal_max: 50
   p2o5_recommended_dose: 8~10 (부족 시)

2. 실무적 기준 (협회):
   p2o5_practical_min: 25
   p2o5_practical_max: 55
   p2o5_recommended_dose: 10~12 (부족 시)

→ 사용자 선택: "정확한 과학" vs "안정적 관행" 토글
```

### 6.2 지역별 맞춤화

```
user_farm 등록 시:
- region_id와 강수 데이터로 보정 계수 자동 적용
- 다우지역(전남·강원영동): RDA × 1.2
- 평년지역(경기·충청): RDA × 1.0
- 소우지역(경북내륙): RDA × 0.9
```

### 6.3 단기 탭 추천 로직

```
if soil_state.p2o5 < 25:
  if region.annual_rainfall > 1500:
    → 과인산석화 70kg + 용성인비 40kg
  else:
    → 과인산석회 60kg + 용성인비 30kg
elif soil_state.p2o5 < 40:
  if region.annual_rainfall > 1500:
    → 용성인비 30~40kg
  else:
    → 용성인비 20~30kg
```

## 7. 보완

### 7.1 현재 gap

1. **비료 가격 미명시**: 추천 비료들의 실제 가격 차이 미분석.
2. **강수량 보정의 과학적 근거 약함**: "강수 많으면 손실 크다"는 원칙이나, 정확한 환산식 없음.
3. **토양 유형별 세분화 부족**: 사양토 vs 식양토의 인산 보유 능력 차이 미반영.
4. **환경 부하 언급 없음**: 인산 과다 시비의 호소 오염 위험 미기재.

### 7.2 다음 검색 키워드

- "강수량과 토양 인산 손실의 정량 관계"
- "과수 토양 유형별 인산 보유 용량"
- "용성인비 vs 과인산석회 효율 비교"
- "비료 가격 추이와 농가 경영비"
- "협회 가이드 2023~2024 업데이트"

### 7.3 연결 문서

- **1번 논문** (RDA 처방): 협회의 기본 표준 (이미 비교됨)
- **2번 논문** (실태조사): 실제 농가가 협회 기준을 따르는가 검증
- **3번 논문** (유기재배): 무기질과 유기의 공존 전략

## 8. 협회 vs RDA vs 실제 농가 삼각형

### 8.1 시비량 추이

```
RDA 이론        협회 실무        농가 관행
8~10 kg/10a  →  10~12 kg/10a  →  22.5 kg/10a (2번 논문)
                                   [+125% 과다]
```

**해석**:
- 협회는 RDA를 25% 상향 (현실 수용)
- 실제 농가는 협회보다 2배 이상 (관행, 초과 안전장치)
- → 전국 인산 축적 문제 발생

### 8.2 교정 필요성

```
교정 경로:
1. RDA 이론 제시
2. 협회 실무 가이드 (1차 조정)
3. 지역별 강수 보정 (2차 조정)
4. 실측 토양값 (3차 조정) ← 매우 중요
5. 연간 모니터링 (피드백 루프)

→ 농가가 단계적으로 "표준"으로 회귀하게 유도
```
