## 2. 데이터 전처리 및 초기값

### 2.1 P2O5 분석법 (RDA 공식 준용)

**분석법**: **Bray-1** (RDA 표준과 동일)
- 원리: 이중산(Bray 시약) 침출
- 단위: mg/kg (건토)
- **매뉴얼에서 제시하는 등급표** (유기재배 기준):

| 토양 유효인산 (mg/kg, Bray) | 등급 | 평가 | 권장 행동 |
|---|---|---|---|
| < 15 | **매우 부족** | 위험 | 즉시 개선 필수 |
| 15~30 | **부족** | 주의 | 시비 권장 |
| 30~50 | **적정** | 양호 | 유지 |
| 50~70 | **충분** | 양호 | 유지 또는 감량 |
| > 70 | **과잉** | 우려 | 시비 중단, 갱신 대기 |

**주의**: 유기재배 기준이 일반 관행 기준(< 30 "부족")보다 **더 낮음**(< 15를 매우 부족으로 본다).  
→ 유기 자재의 효율이 화학비료보다 낮아서, **더 높은 토양 P가 필요**한 이유.

### 2.2 초기값 (매뉴얼 기본 조건)

**유기 사과 과원 표준 초기 토양 특성**:
- pH: 6.0~6.5 (약산성, 유기물 분해 최적)
- EC: 0.8~1.5 dS/m (중간 수준)
- **유효인산**: 40~50 mg/kg 목표
- **유기물**: 30~40 g/kg (퇴비 시용으로 유지)

## 3. 로직

### 3.1 유기재배 인산 관리의 핵심

**원칙**:
1. **화학비료 금지** → 유기질 인산 자재만 사용
2. **자재 효율 낮음** → 토양 P를 더 높게 유지해야 함 (버퍼)
3. **서방성 자재** → 시비 후 효과가 천천히 나타남 (즉시성 없음)
4. **pH 관리 필수** → 토양 P 유효성은 pH에 크게 의존

### 3.2 변수

**독립 변수**:
- 토양 유효인산 (mg/kg, Bray)
- 유기질 자재 종류 (닭/돼지 분뇨 퇴비 vs 해안동물성 vs 혼합)
- 시비 시기 (가을 vs 봄)
- 퇴비 시용량 (톤/10a)

**종속 변수**:
- 토양 유효인산 상승량
- 과실 품질 (유기 인증)

## 4. 결과

### 4.1 유기재배 사과 인산질 자재 시비 기준

| 토양 P (mg/kg) | 1차 개선 년도 | 자재 | 시용량 | 시기 |
|---|---|---|---|---|
| < 15 (매우 부족) | 1년차 | 닭분 퇴비 (유기 인증) + 해안동물성 | 5~8 (P₂O₅ kg/10a) | 9월~10월 |
| 15~30 (부족) | 2~3년 | 혼합 퇴비 또는 해안동물성 | 3~5 (P₂O₅ kg/10a) | 9월~10월 |
| 30~50 (적정) | 유지 | 일반 퇴비 (연 2톤/10a) | 1~2 (P₂O₅ kg/10a) | 9월~3월(분할) |
| > 50 (과잉) | 5년 이상 | **시비 중단** | 0 | — |

### 4.2 유기 인산 자재의 특성

| 자재 | P₂O₅ 함량 | 특징 | 비용 |
|---|---|---|---|
| **닭분 퇴비** (유기 인증) | 3~5% | 신속 (6~12주), 질소도 높음 | 중간 |
| **해안동물성** (어골분 등) | 10~15% | 서방성 (3~6개월), P 고함량 | 높음 |
| **일반 축산 퇴비** (허용 범위) | 1~2% | 저함량이나 유기물 공급 | 낮음 |
| **목초액 기반 액비** | 0.5~2% | 빠른 흡수, 엽면살포 병행 | 중간 |

### 4.3 실제 시비 사례 (매뉴얼 권장)

**사례: 유기 전환 1년차 과원 (P = 20 mg/kg)**

```
목표: P → 40 mg/kg로 상승 (3년 계획)

1년차 (당해):
  - 9월: 닭분 퇴비(유기) 5톤/10a (약 5% P = 250kg P 함유)
  - 추가: 해안동물성(어골분) 300kg/10a (약 12% P = 36kg P)
  - 총 P₂O₅ 투입: 약 6~7 kg/10a
  
  기대 결과: 토양 P +8~10 mg/kg → 28~30 mg/kg 상승
  
2년차:
  - 위와 유사 반복
  
3년차:
  - 토양 P가 40 mg/kg 도달 시, 유지 시비로 전환
  - 연 2톤 일반 퇴비 + 해안동물성 100~150kg/10a
```

### 4.4 화학비료와의 차이

| 항목 | 화학비료 (일반 관행) | 유기 자재 |
|---|---|---|
| 시용량 (P₂O₅ kg/10a) | 8~10 | 5~8 (단, 누적 3년) |
| 즉시성 | 빠름 (2~4주) | 느림 (2~3개월) |
| 토양 P 목표값 | 30~50 mg/kg | 40~60 mg/kg (버퍼) |
| 효율 | 70~80% | 50~60% (서방성) |
| 환경부하 | 저 (정량) | 극저 (유기물 함유) |

## 5. 활용 방안

### 5.1 crop_growth_guide 유기재배 분기

```
crop_id: apple
cultivation_type: organic (신규 필드)
indicator: p2o5
optimal_min: 40 (mg/kg, Bray) — 화학비료보다 높음
optimal_max: 60
allowed_min: 25 (매우 부족 임계값 올려서, 빠른 대응 필요)
allowed_max: 80
weight: 0.15
```

### 5.2 자재 선택 로직

```
user_farm.farming_method = 'organic'이면:
  if soil_state.p2o5 < 25:
    → recommendation: "해안동물성(어골분) 300kg/10a + 닭분퇴비 5톤/10a"
  elif soil_state.p2o5 < 40:
    → recommendation: "혼합퇴비 3톤/10a 가을 시비"
  else:
    → recommendation: "연 2톤 일반퇴비 유지, P 시비 불필요"
```

### 5.3 단기 탭 위험 판정 (유기 전용)

```
if farming_method == 'organic':
  threshold_critical = 25 mg/kg (일반 30보다 낮음)
  threshold_adequate = 40 mg/kg (일반 30보다 높음)
```

## 6. 보완

### 6.1 현재 gap

1. **자재 가격·입수성 미명시**: 해안동물성(어골분)은 지역에 따라 구입 어려움.
2. **토양 미생물 영향 미언급**: 유기 자재는 미생물이 분해해야 하는데, 온도·습도 조건 미분석.
3. **유기 인증 자재 리스트 부재**: "유기 인증 퇴비"의 실제 상품 추천 없음.
4. **화학비료와의 직접 비교 부족**: 본 논문은 유기만 다루고, 혼용 시 효과 미분석.

### 6.2 다음 검색 키워드

- "유기재배 토양 미생물과 양분 가용성"

### 6.3 연결 문서

- **1번 논문** (RDA 일반 기준): 유기 vs 화학 등급표 비교
- **2번 논문** (실태조사): 유기 과원이 포함되어 있는지, 시비량 차이 확인
