# Iteration 2 종합 리포트: 강수/기온이 작물에 미치는 영향 메커니즘

**Status:** Iteration 2-2 (scout 결과)  
**작성:** 자율 연구 루프 Iteration 2  
**데이터 출처:** 다중 학술지 문헌 종합

## 개요

강수(rainfall)와 기온(temperature)이 주요 5작물(사과, 배, 감자, 오이, 상추)의 생육과 수확량에 미치는 영향을 체계적으로 파악한 결과를 정리.

---

## I. 강수 과다 (Waterlogging)

### 메커니즘
```
일 강수 30-50mm(3-5cm) 이상
  ↓
토양 포화 (3-10일 지속)
  ↓
근계 산소 결핍 (<2%)
  ↓
혐기호흡 → 뿌리부패
  ↓
수확량 감소
```

### 정량값 ⭐
| 지표 | 수치 |
|------|------|
| **과습 임계(일강수)** | **30-50mm (3-5cm)** |
| 옥수수 감수 | 3일↑ 수율 급감 |
| 밀 감수 | 6일↑ 수율 저하 |

### 한국 토양별 차이
| 토양질감 | 호우 유출량(mm) | 배수성 |
|--------|-----------------|--------|
| **사양토(모래 많음)** | **23.53** | 양호 |
| 양토 | 10.35 | 중간 |
| **식양토(점토 많음)** | **5.46** | 불량 |

**해석:** 사양토는 배수 양호 → 빠른 유거 발생  
식양토는 배수 불량 → 오래 포화 → **산소결핍 위험 높음**

### 미해결 과제
- 구체 mm 기준값 (국가별, 토양질감별 차이)
- 강수 지속시간 + 토양 투수성 조합 모델

---

## II. 가뭄 (Drought)

### 메커니즘
```
강수 부족 or 고온
  ↓
토양 수분가용량(AWR) 저하
  ↓
식물체 수분스트레스 (-0.2~-0.3 MPa)
  ↓
기공 폐쇄 → 광합성 억제
  ↓
생육 지연, 수확량 감소
```

### 정량값 ⭐
| 수분스트레스 지표 | 수치 | 영향 |
|------------|------|------|
| **AWR <100%** | 제한급수 | 수확량 저해 |
| **AWR <50%** | 심각 | 심각한 위축 |
| **식물 수분포텐셜** | **-0.2~-0.3 MPa** | 기공 폐쇄 시작 |

### 미해결 과제
- AWR 절대값(mm, 토양질감별)
- 생육단계별 가뭄 민감도

---

## III. 고온 피해 (Heat Stress)

### 메커니즘
```
기온 임계값 초과
  ↓
대사 효소 변성, ROS 증가
  ↓
세포막 손상, 광합성 억제
  ↓
착색 불량, 과실 크기 감소, 수확량 저하
```

### 작물별 임계값 ⭐

| 작물 | 고온 임계 | 피해 증상 |
|------|----------|---------|
| **사과** | **31°C** | 일소, 과색 불량 |
| **배** | **~30°C** (추정) | 과색 불량, 일소 |
| **감자** | **28°C (야간)** | 괴경 형성 중단 |
| **오이** | **30°C** | 발아 중단, 분화 저해 |
| **상추** | **30°C** | 발아 중단 |

### 온도 수준별 반응
| 온도 | 반응 |
|------|------|
| >22°C | 부작용 시작(감자, 리뷰) |
| 30°C | 광합성 25%/5°C 감소 |
| 35°C | 극한 조건 (현장 불가) |
| 38°C | 실험실 극한 (괴경 수확량 -14.9%) |

### 미해결 과제
- 배 대기온 기준 고온 임계값 (FST 47.1°C는 과실표면온도)
- 생육단계별 고온 민감도
- 고온 + 저수분 복합 스트레스

## IV. 냉해/서리피해 (Frost Damage)

### 메커니즘
```
야간기온 → 0°C 이하
  ↓
세포 내/외 빙결
  ↓
세포 탈수, 조직 괴사
  ↓
잎/꽃/과실 피해
```

### 작물별 임계값 ⭐

#### **사과** (가장 상세함)
| 생육단계 | 10% 피해 | 90% 피해 |
|---------|---------|---------|
| 개엽기(芽出期) | -5.0°C | -9.4°C |
| 만개기(花滿開期) | -2.2°C | -3.9°C |
| 절대동해 | -30~-35°C | - |

**해석:** 만개기가 개엽기보다 훨씬 예민함 (-2.2°C vs -5.0°C)

#### **감자** (지상부 vs 지하부)
| 부위 | 임계값 | 고사조건 |
|------|--------|---------|
| **잎(지상부)** | **-3°C** | 심각 냉해 |
| **괴경(지하부)** | **-1.5~-2.8°C** | 광범위 고사 |
| 빙핵 형성 | -2.3±0.4°C | 활성 냉해 |

**핵심 발견:** 지상부(-3°C) 보다 지하부(-1.5°C)가 **훨씬 더 예민함** ⭐

#### **배** (저장 냉해)
| 조건 | 임계값 |
|------|--------|
| 저장 온도 | 0°C (냉해 발생) |
| 안전 저장 | -1.1°C (4개월) |

### 미해결 과제
- 배 다른 품종 냉해 기준
- 오이/상추/감자 냉해 기준
- 토양 온도 vs 엽온 괴리

## V. 적산온도(GDD, Growing Degree Day)

### 메커니즘
```
GDD = ∑[(Tmax + Tmin)/2 - Tbase]

누적 온도열 → 생육진도 → 개화→결실→성숙
```

### 작물별 베이스온도 & 값

| 작물 | Tbase | GDD값 | 기준 |
|------|-------|-------|------|
| **배** | **10°C** | **85°C** | ✅ 확정 |
| 사과 | 10°C | (미정) | ⚠️ 필요 |
| 감자 | (미정) | - | ❌ 미정 |
| 오이 | (미정) | - | ❌ 미정 |
| 상추 | (미정) | - | ❌ 미정 |

### 기후변화 영향
- 배 개화 예상: 2071-2100년 약 **20일 조기** (지구 온난화)

### 미해결 과제
- 감자/오이/상추 Tbase, GDD값
- 생육단계별 GDD 체계화
