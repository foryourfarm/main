# 친환경농자재 처리가 배과수원 토양 및 과실품질에 미치는 영향

- **소속:** 단국대학교, 천안시 농업기술센터, 국립원예특작과학원

- **학술지:** 한국유기농업학회지 18(4)
- **URL:** https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001510405

## 6. 보완사항

### 조사의 한계
- **친환경자재 처리 특이성:** 관행재배 배 과수원의 일반 EC/pH 기준과 다를 수 있음 (친환경농자재 조합 처리 효과가 섞여 있어, 일반적인 배 토양 기준값으로 그대로 쓰기 부적절)
- **표본 규모/재배지 대표성:** 천안시 1개 지역(추정) 조사로 전국 대표성 제한 가능성 (원문 미접근으로 확정 불가)
- **2년 단기조사:** 연년 변동성 미반영 가능성

### 원문 미접근으로 인한 한계 (가장 큰 제약)
- EC/pH 측정법(1:5 물추출 vs ECe) 확인 불가
- 처리구별 정량 수치(Table) 확인 불가
- 표본수(N), 정확한 시험포 위치 확인 불가
- 통계적 유의성(p-value) 확인 불가

## 7. 구조적 이슈

### 발견된 방법론 문제
- **측정법 미확인:** EC 단위가 1:5 물추출법인지 ECe(포화침출법)인지 원문 확인 전까지는 registry에 반영 불가 — 값을 넣더라도 단위 환산 오류 위험
- **친환경 vs 관행 기준 분리 필요:** 이 논문은 친환경농자재 "처리 효과"를 보는 연구이므로, 배 토양의 "일반적/관행 기준값"을 그대로 대표하지 않음. registry에 넣을 경우 "친환경자재 처리구 한정" 태그 필수
