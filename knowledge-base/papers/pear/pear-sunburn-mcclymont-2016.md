## 8단계 정리

### 1. 데이터 수집 방법
배 과원 현장 측정  
적외선 온도계로 과실표면온도(FST) 측정

### 2. 표본
적색 배(red-blushed pear) 품종  
태양 노출면 중심

### 3. 메커니즘
과실표면 과열 → ROS 증가 → 항산화 고갈 → 표피 괴사(일소)

### 4. 정량적 결과 ⭐

| 지표 | 수치 |
|------|------|
| **일소 임계값 (FST)** | **47.1°C** |
| 측정대상 | 과실표면온도 |
| 품종 | 적색 배 |

**핵심:** 대기온 기준이 아니라 **과실표면온도(FST)** 기준

### 5. 산업 적용
- 과원 관리(살수, 방충망)
- 품종 선택

### 6. 한계
- 특정 부위(태양 노출면만)
- 특정 시기(성숙기)
- 적색 배만

### 7. 구조적 문제
⚠️ **FST(과실표면) ≠ 대기온**
- 사과 31°C(대기온)와 직접 비교 불가
- 과실표면은 대기온보다 10-20°C 높음

### 8. 새로운 Gap
- 배 대기온 기준 고온 피해 임계값 (미정)
- 다른 배 품종 FST
- 다른 배 품종 대기온 임계값
