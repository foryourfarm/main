## 🏗️ **ML 모델 구축 가능성 평가**

### Phase 1: 현재 데이터로 가능한 것

#### ✅ **즉시 가능 (데이터 완성도 높음)**

1. **분류 모델 (Classification)**
   ```
   입력: 일강수(mm), 일평균기온(°C), 야간최저기온(°C)
   출력: 피해도 레벨 (무해 / 저해 / 심각)
   
   → Random Forest, Logistic Regression
   → 신뢰도: 72% (filled 데이터만 사용)
   ```

2. **냉해 위험 판정기**
   ```
   입력: 야간최저기온(-5~0°C), 개화단계(지상부/지하부)
   출력: 냉해 예측(안전/경고/위험)
   
   → Decision Tree (Boydston/Stegner 임계값 규칙 베이스)
   → 신뢰도: 85% (명확한 임계값)
   ```

3. **과습 피해 위험지수**
   ```
   입력: 일강수(mm), 토양질감(사양토/양토/식양토), 배수성
   출력: 포화도 추정(%) → 피해가능성(%)
   
   → 선형회귀 + 토양질감 계수
   → 신뢰도: 68% (호우유출 데이터 기반)
   ```

#### ⚠️ **조건부 가능 (데이터 보충 필요)**

4. **생육단계별 온도 민감도 모델**
   ```
   입력: 누적일수(파종~개화~결실~성숙), 일평균기온
   출력: 생육진도 예측(%), 고온/냉해 위험도
   
   필요 데이터:
   - GDD 기준값 (감자/오이/상추 미정, 배만 85°C)
   - 생육단계 정의 (국가 표준 필요)
   
   → 로지스틱 회귀 또는 S자곡선 모델
   → 신뢰도: 현재 45% (데이터 부족)
   ```

5. **수확량 예측 모델**
   ```
   입력: 시즌강수(mm), 평균기온, GDD, 냉해일수(-3°C↑), 
         토양pH, EC, AWR
   출력: 예상 수확량(%) = 100% - 감소율(%)
   
   필요 데이터:
   - 극한 조건(38°C 등) 제외한 현장 데이터
   - 작물별 기준 수확량
   - ETc 기반 수분수요 절대값
   
   → 다중회귀, 부스팅(XGBoost)
   → 신뢰도: 현재 52% (데이터 품질 미흡)
   ```
