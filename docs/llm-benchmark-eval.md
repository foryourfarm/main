- Qwen3는 기본이 "생각 모드"라 `think:false`를 안 주면 토큰 예산을 전부 내부 사고에 쓰고 **답변이 빈 문자열로 나오는 경우를 실제로 확인**함(300토큰 캡에서 응답 0자).
