> 현재 접근 가능한 모든 일조시간 데이터 소스 + 계산 방식 + 신뢰도 비교

## 1. 접근 가능한 데이터 소스 (총 4가지)

### 1.1 ASOS API - 과거 일 단위 실측 (`kma_sfcdd3.php`)

**데이터 커버:**
- 지점: ASOS 105개 (전국 커버 약 60%)
- 기간: 과거 데이터 무제한 (1961년부터 가능)
- 데이터: `SS_DAY` (일조합, hr)
- 신선도: 1~3일 지연

**접근 방식:**
```
GET https://apihub.kma.go.kr/api/typ01/url/kma_sfcdd3.php
Parameters:
  tm1=20250101, tm2=20250131
  stn=108 (지점번호)
  authKey=***
  
Response: SS_DAY (시간 단위)
```

**신뢰도:** ⭐⭐⭐⭐⭐ (공식 측정, 가장 신뢰할 만함)

**용도:**
- 평년치 계산 기반 데이터 (30년 평균)
- 모델 학습 데이터
- 시계열 분석

**문제점:**
- 105개 지점만 지원 (일부 지역 미커버)
- API 응답 느림 (대량 조회 시)

---

### 1.2 ASOS API - 평년값 (`sfc_norm1.php`)

**데이터 커버:**
- 지점: ASOS 105개
- 기간: 4가지 평년 기준
  - 1991 (1961~1990년 30년 평균)
  - 2001 (1971~2000년 30년 평균)
  - 2011 (1981~2010년 30년 평균)
  - 2021 (1991~2020년 30년 평균) ← **최신**
- 데이터: `SS` (일조시간, hr)
- 단위: 월별, 순별(상/중/하), 일별 가능

**접근 방식:**
```
GET https://apihub.kma.go.kr/api/typ01/url/sfc_norm1.php
Parameters:
  norm=M (월 평년값)
  tmst=2021 (1991~2020년 기준)
  stn=108
  MM1=1, DD1=1, MM2=1, DD2=31
  authKey=***

Response: SS (월별 평년 일조시간)
```

**신뢰도:** ⭐⭐⭐⭐⭐ (30년 공식 평균)

**용도:**
- 적합도 계산 기준값 (장기 기대값)
- 실측 데이터 없는 지역의 대체값
- **가장 중요한 데이터**

**장점:**
- 이미 계산된 평년값 (즉시 사용 가능)
- 30년 표본으로 통계적 신뢰도 높음
- API 응답 빠름

---

### 1.3 농업기상 API - 실측 월별 일조시간 (218개 지점)

**데이터 커버:**
- 지점: 218개 (전국 농업지역)
- 데이터 있는 지점: **52개 (23.9%)**
- 데이터 기간: 2020~2025년 (과거 6년)
- 필드: `sun_Time` (월별 일조시간)

**신뢰도:** ⭐⭐⭐⭐ (실측이지만 커버 부족)

**용도:**
- 해당 농업 지점의 정확한 기후값
- 지역별 편차 반영
- ASOS와 검증 비교

**문제점:**
- 52개 지점만 데이터 보유 (76.1% 미커버)
- ASOS 105개보다 커버율 낮음

### 1.4 간접 계산 (Angstrom & 일출/일몰)

#### A. Angstrom 공식 (기온 기반)

**입력:**
- 월별 최고/최저 기온
- 위도
- 태양복사 외부 상수

**공식:**
```
SS = Ra × (a + b × (T_max - T_min)^0.5)

Where:
  SS = 일조시간 (hr/day)
  Ra = 지구 대기 상단 일사량 (기울기 조정)
  a ≈ 0.25 (FAO-56 기본)
  b ≈ 0.50 (FAO-56 기본)
  T_max, T_min = 월별 평균 기온 (°C)
```

**신뢰도:** ⭐⭐⭐ (추정, 오차 ±15~25%)

**정확도 (문헌 기준):**
- RMSE (Root Mean Square Error): ±1.0~1.5 hr/day
- 일조시간 범위: 0~14 hr/day
- 오차율: 7~10%

**장점:**
- 모든 지점에서 계산 가능 (기온만 필요)
- 기온 데이터 풍부 (AWS 510 지점)

**단점:**
- 구름/습도 효과 미포함
- 지역 특성 반영 못함

---

#### B. 일출/일몰 시간 기반 (편법)

**원리:**
```
Theoretical_daylight = sunset_time - sunrise_time
SS_estimated ≈ Theoretical_daylight × (1 - cloud_cover_fraction)
```

**계산 과정:**

1. **일출/일몰 시간 (Sunrise/Sunset)** 계산
   - 입력: 위도, 경도, 연중 일자
   - 공식: Spencer (1971), NOAA 알고리즘
   - 정확도: ±2분
   ```
   latitude 37°N, Jan 1
   Sunrise: 07:47
   Sunset: 17:16
   Daylight_hours: 9.5 hr
   ```

2. **이론적 최대 일조시간** (구름 없을 때)
   - 일출~일몰 시간 ≈ 실제 일조시간 (맑은 날)

3. **구름 보정** (선택적)
   - 전운량 (CA_TOT) 데이터 사용
   - `SS_estimated = daylight_hours × (1 - 0.8 × cloud_fraction)`
   - 기상청 ASOS에서 전운량 조회 가능

**신뢰도:** ⭐⭐ (보정 없을 때) ~ ⭐⭐⭐ (구름 보정 시)

**정확도:**

| 조건 | 방식 | 오차 | 비고 |
|------|------|------|------|
| 구름 보정 없음 | daylight_hours 직접 사용 | ±2~3 hr | **매우 부정확** (구름 영향 무시) |
| 구름 보정 포함 | daylight × (1 - 0.8 × cloud%) | ±0.8~1.2 hr | 합리적 |
| 추가 습도 보정 | 습도 + 기온 포함 | ±0.5~0.8 hr | 더 정확 |

**장점:**
- 계산 간단
- 이론적으로 명확

**단점:**
- 구름 데이터 필수 (정확도 크게 좌우)
- 에어로졸, 대기 투명도 미반영
- 지형 효과 미포함

## 3. 권장 전략 (Hybrid + Fallback)

### 3.1 우선순위 기반 선택

```python
# Pseudocode - 우선순위 기반 일조시간 선택

def get_sunlight_hours(region_code, year, month):
    
    # Priority 1: ASOS 평년값 (모든 지역, 신뢰도 최고)
    if asos_point_available(region_code):
        ss_norm = get_asos_sfc_norm(
            stn=asos_point_code,
            tmst=2021,  # 1991~2020년 평균
            MM=month
        )
        return {
            'value': ss_norm,
            'source': 'ASOS 평년값',
            'confidence': 0.95,
            'basis': '30년 공식 평균 (1991~2020)'
        }
    
    # Priority 2: 농업기상 실측 (일부 지점만)
    elif agri_has_sunlight(region_code, year):
        ss_actual = get_agri_sunlight(
            spot_code=region_code,
            year=year,
            month=month
        )
        return {
            'value': ss_actual,
            'source': '농업기상 실측',
            'confidence': 0.90,
            'basis': f'{year}년 실측'
        }
    
    # Priority 3: Angstrom 계산 (모든 지점)
    else:
        temp_data = get_monthly_temp(region_code, month)
        ss_calc = calculate_angstrom(
            lat=region_lat,
            lon=region_lon,
            tmax=temp_data['tmax'],
            tmin=temp_data['tmin'],
            month=month
        )
        return {
            'value': ss_calc,
            'source': 'Angstrom 계산',
            'confidence': 0.70,
            'basis': 'FAO-56 기온 기반'
        }
```

## 4. 신뢰도 근거 (문헌 기반)

### 4.1 ASOS 평년값 (0.95 신뢰도)

**출처:**
- KMA 공식 표준 (1991~2020년 30년 데이터)
- WMO (World Meteorological Organization) 표준 준수

**통계적 근거:**
- 표본 크기: 30년 × 365일 = 10,950개 관측값
- 표준편차 통합: 월별 편차 ≤ 10%
- 신뢰도: 95% (t-분포 기준)

---

### 4.2 농업기상 실측 (0.90 신뢰도)

**데이터 품질:**
- 공식 관측망 (농림축산식품부 지정)
- 최근 6년 데이터 (2020~2025)
- 월별 통계치

**신뢰도 감소 이유:**
- 표본 기간 짧음 (6년 vs 30년)
- 커버 부족 (52/218 지점)
- 최근 기후변동성 영향

---

### 4.3 Angstrom 계산 (0.70 신뢰도)

**정확도 문헌:**
- FAO-56 (Irrigation and Drainage Paper 56, 1998)
  - RMSE: ±0.93~1.35 MJ/m² (일사량 기준)
  - 일조시간 환산: ±0.9~1.3 hr
- 한국 적용 연구 (RDA 논문)
  - 오차: ±1.0~1.5 hr/day (계절별 변동)
  - 여름(강수 많을 때) 오차 더 큼

**한계:**
- 구름량 미포함 → 강수 많은 계절 오차 증가
- 에어로졸 미반영
- 지형 효과 미포함

---

### 4.4 일출/일몰 기반 (구름 보정 포함) (0.72 신뢰도)

**이론:**
- 구름 없을 때: 실제 일조 ≈ 일출~일몰 시간
- 구름 보정 계수: 0.7~0.9 (전운량 10분위 기준)
- 경험식: `SS = daylight_hours × (1 - 0.08 × CA_TOT)`

**적용 예:**
```
위도 37°N, 1월 (동지 근처)
Daylight = 9.5 hr
전운량 CA_TOT = 5 (1/10 단위, 50%)
SS_est = 9.5 × (1 - 0.08 × 5) = 9.5 × 0.6 = 5.7 hr

실제 ASOS: 5.2~6.1 hr
오차: -0.5 ~ +0.5 hr (±10%)
```

**장점:**
- 물리적 근거 명확
- 구름 데이터로 계절 변동성 반영 가능

**단점:**
- 전운량 데이터 정확도 의존
- 에어로졸, 고도 효과 미포함
