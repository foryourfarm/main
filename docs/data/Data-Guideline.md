# Data-Guideline.md

> AI 기반 토양 화학성 변화 예측 모델 MVP 데이터 가이드라인
> 목적: 문헌 기반 이론 로직 + 공공데이터를 활용한 "농부의 행위 → 토양 화학성 변화" 예측 모델 구축

---

## 0. 프로젝트 개요 및 기본 구조

### 예측 문제 정의
"농부의 특정 행위(시비, 유기물 투입 등) → 토양 화학성 3개 변수(pH, 유기물, 유효인산)의 변화량"을 예측한다.

### 변수 구조 (4층 구조)
| 층위 | 변수 | 역할 |
|---|---|---|
| **처치변수 (Treatment)** | 시비 종류·양·시기, 유기물 투입 등 | 우리가 개입하는 입력 |
| **종속변수 (Y)** | pH, 유기물, 유효인산 | 다변량 출력 (서로 인과적으로 얽혀 있음) |
| **시간불변 조절변수** | 심토토성, 심토자갈함량, 경사도 | 지역별로 상이, 반응 강도·속도를 조절 |
| **시간가변 외생변수** | 기온, 강수량 | 반응 속도(무기화·용탈)에 영향 |

### 종속변수 간 관계 (중요)
세 종속변수는 서로 독립이 아니라 다음의 인과 구조를 가진다.
- **pH → 유효인산**: pH가 유효인산의 가용도(용해도)를 화학적으로 결정. 중성 부근에서 인산 가용도 최대, 산성/알칼리성에서 불용성 화합물 형성.
- **유기물 → pH, 유효인산 (배경조건)**: 유기물은 양이온치환용량(CEC)과 완충능(buffering capacity)을 결정하는 배경 조건. 유기물 함량이 높으면 pH가 급변하지 않고, 유효인산도 안정적으로 유지됨.
- 따라서 모델링 시 세 변수를 완전 대칭적 다중출력으로 다루기보다는, **"유기물(배경) → pH → 유효인산"의 계층/순차적 구조**를 고려할 것.

## 1. 사용할 공공데이터 및 변수 매핑

### 흙토람 OpenAPI (국립농업과학원)

| API | 매핑되는 변수 층위 | 역할 |
|---|---|---|
| **농경지화학성 통계정보 V2** | 종속변수 (Y) | pH, 유기물, 유효인산의 읍면동 단위 통계 → 기본 목표 변수 |
| **토양검정 화학성 상세정보 V2** | 종속변수 (Y) - 실측 검증용 | 필지(PNU) 단위 실측치. 지난 3년 시계열 확보 시 준실측 검증 데이터로 활용 |
| **토양도 기반 토양특성 단면정보 V2** | 시간불변 조절변수 | 심토토성, 심토자갈함량, 경사도 |
| **작물별 비료 표준사용량 처방 정보** | 처치변수 인코딩 참조 | "표준 시비량 대비 편차"를 계산하기 위한 baseline |
| **작물코드 목록 정보** | 처치변수 인코딩 참조 | 작물 식별 및 매핑 테이블 |

### 농업기상정보서비스 (국립농업과학원)

| API | 매핑되는 변수 층위 | 역할 |
|---|---|---|
| **농업기상 기본 관측데이터** | 시간가변 외생변수 | 기온, 강수량 (일별/월별) |
| **농업기상 관측지점 상세정보** | 참조 데이터 | 관측지점 위경도 → 필지-관측지점 매핑용 |

### 제외한 데이터와 이유
- **토양적성등급 통계 (최적지/적지/가능지/저위생산지)**: 화학성 결과를 종합해 산출된 파생변수. 목표 변수와 다중공선성 및 정보 순환 위험.
- **비료사용처방 정보/체험 정보**: 화학성을 입력으로 받아 처방을 출력하는 방향이라 인과 방향이 반대.
- **토양특성 통계정보 V2 (면적 통계)**: 필지 단위 화학성 변화와 무관한 면적 분포 통계.
- **친환경 인증**: 화학적 변화의 원인이 아닌 행정 라벨.
- **농업유전자원, 스마트팜(온실), 농업인건강안전, 신기술보급사업**: 프로젝트 도메인(노지 토양 화학성)과 무관.
- **기상청 단기예보, 날씨누리**: 미래 예보용. 과거 행위-반응 학습에는 기상자료개방포털(과거 통계)로 충분.
- **작물별 토양적성 통계 V2**: 위와 동일한 파생변수 이슈.

### 2-1. 농경지화학성 통계정보 V2 (종속변수 원자료)

| 필드 | 의미 | 역할 |

| --------- | ---------- | ------------------------------------------- |

## 3. 얼마나 많은 지역 데이터가 필요한가

### 결론
**MVP 1차: 최소 30~50개 읍면동, 이상적으로는 100~200개 읍면동.**

### 근거
- **통계학적 최소 요건**: 회귀 계열 모델에서 안정적 추정을 위해 통상 "예측 변수 수 × 10~20"의 관측치가 권장됨. MVP에서 조절변수(토성, 경사도, 기온, 강수) 포함 5~8개 정도라면 최소 50~150개 데이터 포인트 필요.
- **지역 다양성 요건 (토양학적)**: 한국의 토양 유형은 매우 이질적임. 최소한 다음 축을 커버해야 이론 로직이 지역별로 다르게 작동하는 현상을 학습할 수 있음.
  - **토성 다양성**: 사토질/양토질/식토질을 각각 최소 10개 이상 포함
  - **기후대 다양성**: 남부(온난 다우) / 중부 / 북부(냉량) 각각 포함
  - **경사도 다양성**: 평탄지(논 중심)와 경사지(밭·과수원) 모두 포함
- **가우시안 프로세스(GPR)의 특성**: GPR은 소량 데이터(수십~수백 개)에서도 안정적으로 작동하므로, 무리하게 전국을 다 커버할 필요는 없음. 다만 **다양성이 부족하면 특정 조건 밖에서는 예측 신뢰구간이 매우 넓어짐** → "다양성 > 절대 개수"

### 권장 전략
1. **MVP 0단계 (프로토타입)**: 특정 도(예: 경기도) 내 30~50개 읍면동으로 파이프라인 검증
2. **MVP 1단계 (본 실험)**: 전국 100~200개 읍면동, 위 3개 다양성 축을 층화표집(stratified sampling)으로 배분
3. **확장 단계**: 필지 단위 데이터(토양검정 화학성 V2)를 500~1,000 필지 이상 추가 확보 시 실측 검증 가능

## 4. 시계열 데이터는 얼마 동안의 기간을 이용해야 하는가

### 결론
**최소 5년, 권장 10년, 이상적으로 15~20년의 데이터 사용.**

### 근거

**농경지 화학성 통계정보의 특성**
- 국내 농경지 토양 화학성 조사는 대체로 4년 주기로 시·군 단위 반복 수행. 즉 한 지역의 데이터 포인트는 4년에 1건씩 갱신됨.
- **5년치 = 지역당 1~2개 관측점**만 확보되어 시계열 학습 난이도가 매우 높음.
- **10년치 = 지역당 2~3개 관측점**으로, 최소한의 변화 추세 학습 가능.
- **15~20년치 = 지역당 4~5개 관측점**, 이 정도 되어야 "정책 변화 전후의 차이" 같은 준실측 검증도 가능.

**토양 화학성 변화의 시간 척도**
- pH나 CEC는 완충능 때문에 **한두 해로는 크게 변하지 않는 안정 변수**. 5년 이하 데이터로는 시비 효과가 노이즈에 묻힘.
- 유기물은 특히 변화가 느려서(반감기 수년~수십 년), **최소 10년 이상**의 시계열이 있어야 유의미한 추세 파악 가능.
- 유효인산은 상대적으로 반응이 빠르지만, 그럼에도 시비 이력이 누적되어 나타나므로 5년 이상 권장.

**기상 데이터**
- 종속변수(토양 화학성) 관측 시점과 동일한 기간을 커버해야 함.
- 다만 기상은 일별/월별로 풍부하므로, 종속변수 관측 시점 **직전 1~5년 누적/평균**을 피처로 파생시켜 사용(예: "최근 3년 평균 강수량", "최근 5년 적산온도").

### 권장 전략
- **필수**: 농경지 화학성 통계정보 **최근 10년치**(현실적 하한선)
- **권장**: **15년치 이상**, 특히 유기물 예측 정확도를 위해
- **기상**: 화학성 관측 시점 **직전 5년치 월별 데이터**를 파생 변수로 가공

## 5. CSV 파일 구성 방식

### 결론
**정규화된 4개 CSV로 나눌 것을 강력히 권장.** 단일 파일로 합치지 말 것.

### 근거
- 시간 스케일이 서로 다름 (기상은 일/월 단위, 화학성은 연 단위, 토성은 시간 불변)
- 하나의 큰 파일로 합치면 기상 데이터 때문에 화학성 값이 수십 배 중복 저장되어 파일이 비대해지고, 실수로 통계 산출 시 이중 계산 위험
- 관계형 구조로 두면 나중에 변수 추가·삭제가 유연함

### 파일 구성

#### `01_soil_chemistry.csv` (종속변수 Y — 핵심 원자료)
```
region_code, year, pH, organic_matter, available_p, k, ca, mg, silicic_acid
```
- **region_code**: 법정동 10자리 (조인 키)
- **year**: 조사연도 (시계열 정렬 키)
- pH, organic_matter, available_p: MVP 사용 변수
- k, ca, mg, silicic_acid: 확장용 보관(사용 안 함, 폐기하지 말 것)

#### `02_soil_physical.csv` (시간불변 조절변수)
```
region_code, subsoil_texture_code, subsoil_gravel_code, slope_code
```
- **region_code**: 조인 키 (01과 동일 코드 체계)
- 각 코드는 흙토람 코드북 매핑 필요 → 별도 코드북 CSV 준비 권장

#### `03_weather_monthly.csv` (시간가변 외생변수)
```
region_code, year, month, avg_temp, precipitation
```
- **region_code**: 조인 키
- 기상관측지점을 법정동에 매핑하는 별도 로직 필요 (가장 가까운 관측지점 또는 시·군 대표 지점 사용)
- **월별로 유지 권장** — 나중에 "1~5월 누적 강수", "생육기 적산온도" 등 다양한 파생 변수 생성 가능

#### `04_treatment_reference.csv` (처치변수 인코딩용 참조 테이블)

## 6. 추천 머신러닝 모델과 근거

### 최종 추천: 다중출력 가우시안 프로세스 회귀 (Multi-Output GPR)

### 선정 이유

**① 불확실성이 모델 출력에 내장됨 (가장 중요)**
- 실측 검증 데이터가 부족한 현 상황에서, "예측값 하나"보다 "예측값 + 신뢰구간"이 훨씬 유용.
- 사용자(농부/정책 담당자)에게 "이 예측은 얼마나 확실한가"를 정직하게 전달 가능.

**② 본질적으로 베이지안 구조**
- 문헌 기반 이론 로직에서 나온 계수를 **사전분포(prior)**로 인코딩 가능.
- 나중에 토양검정 실측 데이터가 하나씩 들어와도 전체 재학습 없이 **사후분포(posterior) 업데이트** 가능.
- 이는 지금 상황(초기엔 이론치만 있고, 점진적으로 실측 확보)에 가장 잘 맞는 워크플로우.

**③ 소량 데이터에 강함**
- MVP 데이터 규모(수십~수백 지역)에서도 안정적으로 작동.
- 딥러닝 계열은 과적합 위험이 크지만, GPR은 데이터가 적을수록 오히려 유리한 케이스가 많음.

**④ 액티브 러닝(Active Learning)과 궁합이 좋음**
- 예측 분산이 큰 지역/조건을 우선적으로 실측 조사 대상으로 선정 가능.
- "다음에 어디를 측정해야 가장 정보가 많은가"를 알려주는 부가 가치.

**⑤ 종속변수 간 상관관계 반영 가능**
- pH, 유기물, 유효인산이 서로 얽혀 있는 구조를 **다중출력 GP(Coregionalization)**로 자연스럽게 모델링.
- 한 변수의 예측이 다른 변수의 예측 정확도에도 기여함.

### 보조 모델: LightGBM Quantile Regression
- GPR과 교차검증용으로 병행 사용.
- 비선형·상호작용을 강하게 잡아내는 데 유리하고, Quantile Regression으로 예측 구간도 산출 가능.
- 두 모델의 예측이 크게 어긋나는 지점은 "구조적 불확실성이 큰 영역"으로 표시.

### 사용하지 않을 이유가 있는 모델
- **일반 MLP·랜덤포레스트**: 이론치를 잘 재현하는 함수가 될 뿐, 불확실성 정보 없음.
- **강화학습(RL) 단독**: 보상 함수가 이론치라서 "이론치 세계에서만 최적"인 정책 학습. Sim-to-real gap 문제.
  - 단, "이론치가 맞다는 가정 하에 최적 행위 조합 추천"이 필요하면 GPR 예측 위에 RL 얹는 하이브리드는 가능.
- **비지도학습 단독**: 인과관계 학습 도구가 아님.
  - 단, 지역별 토양 유형 클러스터링에는 유용 → GPR 학습 전 지역 층화 목적으로 사용 권장.

### 최종 아키텍처 요약
```
[전처리]
비지도 클러스터링 (지역 층화)
   ↓
[핵심 모델]
다중출력 GPR
- 입력: 처치변수 + 시간불변 조절변수 + 시간가변 외생변수
- 출력: pH, 유기물, 유효인산 (상관구조 반영)
- 사전분포: 문헌 기반 이론 계수
   ↓
[검증/교차분석]
LightGBM Quantile Regression 병행
   ↓
[업데이트 루프]
실측 데이터 확보 시 GPR 사후분포 업데이트
   ↓
[액티브 러닝]
예측 분산 큰 지점 → 다음 실측 우선순위
```

### 라이브러리 추천
- **GPR**: GPyTorch (다중출력·대규모 데이터에 강함) 또는 GPflow
- **Quantile GBM**: LightGBM 내장 `objective='quantile'`
- **클러스터링**: scikit-learn의 KMeans / GaussianMixture
