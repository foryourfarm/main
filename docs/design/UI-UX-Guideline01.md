# UI/UX 가이드라인 - 방안 1: "따뜻한 신뢰감, 농촌 감성"

**디자인 컨셉**: 자연 친화적이고 포근한 톤으로, 농촌 공동체와 정직한 관계를 느끼게 하는 인터페이스

**레퍼런스**: 농촌 문화권 농업정보 앱 (기상청, 국립농산물품질관리서비스), 전통 공예 브랜드 UI, 신뢰감 있는 금융앱 디자인

---

## 1. 디자인 컨셉

### 핵심 철학
- **정직한 투명성**: 데이터의 근거·한계를 숨지 않고 명시 → 전문성 신뢰감
- **손으로 만진 듯한 감정성**: 직선만이 아니라 살짝 곡선, 자연스러운 여백
- **계절과 흙의 색상**: 녹색, 갈색, 흙색 중심의 팔레트로 "농업"을 직관적으로 표현
- **공동체 의식**: 혼자가 아니라 같은 길을 가는 이웃들과 함께하는 느낌

### 주요 특징
- 따뜻한 어조의 문구와 시각
- 시간·계절 흐름을 보여주는 선형 다이어그램
- 신뢰감 있는 배지/아이콘 (관공서 느낌)
- 사진/일러스트로 실제 현장감 전달

## 3. 타이포그래피

### 폰트 패밀리

#### 본문 (Body Text)
- **한글**: Noto Sans KR (Google Fonts)
  - 가중치: Regular (400), Bold (700)
  - 이유: 친숙하고 읽기 쉬운, 공공기관 표준 폰트
  - 다운로드: https://fonts.google.com/noto/specimen/Noto+Sans+KR

- **영문** (숫자, 단위): Inter (Google Fonts)
  - 가중치: Regular (400), Bold (700), SemiBold (600)
  - 이유: 현대적 가독성, 숫자 명확함
  - 다운로드: https://fonts.google.com/specimen/Inter

#### 제목 (Headlines)
- **한글**: Noto Serif KR (Google Fonts)
  - 가중치: Bold (700), ExtraBold (800)
  - 이유: 전통과 신뢰감, 신문 느낌
  - 다운로드: https://fonts.google.com/noto/specimen/Noto+Serif+KR

#### 데이터/지표 (Numbers, Units)
- **모노스페이스**: JetBrains Mono (Google Fonts)
  - 가중치: Regular (400), Bold (700)
  - 이유: 정확한 수치 표현, 코드 같은 신뢰감
  - 다운로드: https://fonts.google.com/specimen/JetBrains+Mono

### 크기 체계 (Scale)

| 용도 | 크기 | 행높이 | 가중치 | 예시 |
|------|------|--------|--------|------|
| H1 (페이지 제목) | 28px / 32px(데스크) | 1.4 (39px) | 700 | "대시보드", "약력" |
| H2 (섹션 제목) | 22px / 24px(데스크) | 1.4 (31px) | 700 | "오늘의 위험 신호", "이번 시즌 목표" |
| H3 (서브 제목) | 18px / 20px(데스크) | 1.4 (25px) | 600 | 카드 타이틀 |
| Body Large | 16px | 1.5 (24px) | 400 | 본문, 설명 |
| Body Regular | 14px | 1.5 (21px) | 400 | 일반 텍스트 |
| Body Small | 12px | 1.5 (18px) | 400 | 라벨, 보조 텍스트 |
| Caption | 11px | 1.4 (15px) | 500 | "갱신됨 2024-07-23 14:00" |
| Number (수치) | 20px / 24px(강조) | 1.2 | 700 | 적합도 점수 "85" |

### 타이포그래피 원칙
1. **가독성 우선**: 초보 농업인이 밭에서 햇빛 아래서도 읽을 수 있는 크기와 대비
2. **한글-영문 조합**: "EC 2.1 dS/m" 같은 혼합 텍스트는 한글과 영문 폰트 구분 (가독성)
3. **숫자는 명확하게**: 작물 수확량, 토양 pH, 적합도 점수는 JetBrains Mono로 (헷갈림 방지)
4. **감정 로깅**: Noto Serif는 "어려운 기술 용어 같지만 우리 편이다"는 신뢰감

## 4. 레이아웃 원칙

### 그리드 시스템
- **모바일 (320px ~ 768px)**: 4-column grid, 12px gutter
- **태블릿 (768px ~ 1024px)**: 8-column grid, 16px gutter
- **데스크톱 (1024px+)**: 12-column grid, 20px gutter

### 여백 시스템 (Spacing Scale)
```
4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px
```

적용 예:
- **컴포넌트 내 여백**: 12px (텍스트 라벨과 아이콘)
- **카드 간 여백**: 16px (모바일), 24px (데스크톱)
- **섹션 간 여백**: 32px (모바일), 48px (데스크톱)
- **페이지 가장자리**: 16px (모바일), 32px (데스크톱)

### 반응형 Breakpoint

| 기기 | 너비 | 사항 |
|------|------|------|
| 모바일 (초소형) | 320px ~ 374px | 한손 조작, 텍스트 크기 키움 |
| 모바일 (표준) | 375px ~ 540px | 기준선 (대부분 귀농인 폰) |
| 모바일 (대형) | 541px ~ 768px | 스택 2개 기준 |
| 태블릿 | 769px ~ 1024px | 2-3 열 레이아웃 |
| 데스크톱 | 1025px+ | 3-4 열 레이아웃 |

### 모바일 우선 설계
1. **한손 조작 존**: 화면 아래 50%를 주요 버튼(오늘의 추천, 더 알아보기)으로 채움
2. **터치 타겟**: 최소 48px × 48px (특히 고령자 대상)
3. **스크롤 방향**: 수직 스크롤 우선 (수평 스크롤 최소화)
4. **가로 화면**: 가로/세로 자동 전환 지원 (밭에서의 각도 다양성)

### 카드 레이아웃
```
모바일:
┌─────────────────────────┐
│  [아이콘] 제목 (H3)     │ 16px padding
│                         │
│  본문 설명 (Body Reg)  │
│                         │
│  [위험도 배지] [갱신시각] │
│  [액션 버튼]             │
└─────────────────────────┘
```

## 6. 인터랙션 & 애니메이션

### 원칙
> "정확성을 해치지 않는 범위에서, 따뜻한 감정을 전달하는 마이크로 인터랙션"

### 페이지 전환
- **진입 애니메이션**: 아래에서 위로 슬라이드 (250ms, ease-out)
  - 느낌: 자연스럽고, 급하지 않은, 신뢰감 있는
- **퇴장 애니메이션**: 위에서 아래로 페이드 (150ms, ease-in)

### 버튼 상호작용
- **홀딩 (Press)**: 배경색 10% 어두워짐 (즉시, 시각적 피드백)
- **활성화 (Active)**: 텍스트 아래 1px 언더라인 (200ms, ease-out)
- **비활성화 (Disabled)**: 투명도 60%, 클릭 불가

### 카드 호버 (데스크톱만)
- **섀도우 깊어짐**: box-shadow 0 8px 16px rgba(26, 24, 21, 0.12) (200ms, ease-out)
- 배경색 변화 없음 (너무 산만하지 않게)

### 데이터 로딩
- **스켈레톤 로더**: 밝은 회색 (#E8E6E1)에서 약간 더 밝은 회색으로 깜박임 (1.5초 반복)
- 회전 스피너 없음 (농촌 감성과 맞지 않음)

### 알림 토스트
```
위험 신호 발생 시:
```

## 7. 접근성 고려사항

### 색상 대비 (Color Contrast)
모든 텍스트와 배경은 **WCAG AAA 표준 준수** (최소 7:1):

| 조합 | 대비율 | 준수 |
|------|--------|------|
| 자연 녹 (#2D5016) + 흰색 (#FAFAF7) | 11.2:1 | ✓ AAA |
| 곡식 황금 (#D4AF37) + 검정 (#1A1815) | 5.8:1 | ✓ AAA |
| 진한 회색 (#4A4643) + 흰색 (#FAFAF7) | 8.5:1 | ✓ AAA |

### 색맹 대응
- **적합도 등급**: 색상만으로 표현하지 않음. 반드시 **문자 라벨** (S/A/B/C) + 아이콘 병기
- **위험도**: 색상 + 아이콘 (⚠️/!/✓) + 텍스트 필수
- **테스트**: Protanopia (적색맹), Deuteranopia (녹색맹) 시뮬레이션으로 검증

### 터치 타겟
- 최소 크기: **48px × 48px** (손가락 기준)
- 버튼, 링크, 폼 요소 모두 준수
- 타겟 간 최소 8px 여백 (실수로 누르는 것 방지)

### 포커스 가시화 (Keyboard Navigation)
```
포커스 상태: 2px #2D5016 테두리 + 4px 여백
예: 버튼 포커스
┌──────────────────────────────┐
│  [버튼 텍스트]               │
└──────────────────────────────┘
     ↑ 명확한 초록 테두리
```

### 화면 판독기 (Screen Reader) 호환성
- **링크**: "< 자세히 보기"가 아니라 "오이 적합도 자세히 보기"
- **이미지**: `alt="S등급, 우수, 녹색 게이지 85점"`
- **폼 라벨**: `<label for="crop-select">작물 선택</label>`
- **섹션 제목**: `<h2>오늘의 위험 신호</h2>`
- **라이브 리전**: 새 경고 도착 시 `aria-live="polite"` 선언

### 글씨 크기 조정
- 기본 단위: `rem` (상대 크기) — 사용자 브라우저 설정 존중
- 고정 단위 `px` 사용 금지 (특히 폰트)
- 테스트: 200% 줌 시에도 레이아웃 깨지지 않는지 확인

### 모션 감응증 (Vestibular Sensitivity)
```css
@media (prefers-reduced-motion: reduce) {
  /* 모든 애니메이션 즉시 또는 제거 */
  animation-duration: 0.01ms !important;
  transition-duration: 0.01ms !important;
}
```

### 암 모드 (Dark Mode)
- 밭에서 저녁/야간 사용을 고려해 자동 전환 지원
- iOS/Android 기본 설정 존중 (`prefers-color-scheme`)
- 다크 모드에서도 명도 대비 AAA 준수
