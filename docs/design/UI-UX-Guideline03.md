# UI/UX 가이드라인 - 방안 3: "친근하고 명확, 정보 우선"

**디자인 컨셉**: 저문해력, 농촌 지역 사용자를 위한 직관적이고 시각-음성 중심 인터페이스

**레퍼연스**: BHIM UPI Lite (인도 농촌 사용자), WhatsApp, 음성 앱 (Google Assistant, Alexa), 이모지/아이콘 중심 인터페이스 (Duolingo, LINE 카톡), 농촌 지역 기상 앱

---

## 1. 디자인 컨셉

### 핵심 철학
- **텍스트 최소화**: 아이콘, 이모지, 색상으로 의사소통
- **시각적 명확성**: 첫눈에 "무엇"을 해야 할지 알 수 있어야 함
- **음성/음향 보조**: 낮은 문해율 사용자도 앱을 "이용"할 수 있게
- **큰 터치 타겟**: 글러브 착용, 고령, 저시력자 모두 조작 가능
- **정서적 친근감**: "복잡한 과학" 아니라 "아는 이웃이 조언해주는 느낌"

### 주요 특징
- 큰 아이콘 + 짧은 문구
- 이모지로 상태 표현 (🟢 안전, 🟡 주의, 🔴 위험)
- 컬러풀하지만 의미 있는 색상 (각각이 고유한 의미)
- 음성 가이드 또는 자막 지원
- 오프라인 모드 지원 (적어도 캐시된 정보는 접근 가능)

## 2. 컬러 팔레트

### Semantic Primary Colors (의미별)
| 색상 | Hex | 의미 | 이모지 | 사용 |
|------|-----|------|--------|------|
| 안전 녹 | `#4CAF50` | 안전, 진행 OK | 🟢 | 정상, S등급 |
| 주의 노랑 | `#FDD835` | 주의, 준비 필요 | 🟡 | 보정, B등급 |
| 위험 빨강 | `#F44336` | 위험, 즉시 행동 | 🔴 | 긴급, C등급 |
| 정보 파랑 | `#2196F3` | 정보, 제안 | 🔵 | 팁, A등급 |

각 색상은 **독립적인 의미**를 가지며, 항상 **이모지 + 아이콘 + 텍스트 라벨** 3가지로 표현됨.

### Neutral Colors
| 색상 | Hex | 용도 |
|------|-----|------|
| 흰색 | `#FFFFFF` | 배경 |
| 밝은 회색 | `#F0F0F0` | 보조 배경 |
| 중간 회색 | `#9E9E9E` | 비활성 요소 |
| 검정 | `#212121` | 텍스트 |

### 이모지 & 심볼
```
안전: 🟢 ✓ 👍 ⭕
주의: 🟡 △ ⚠️ ❗
위험: 🔴 ✗ ⛔ ⚠️⚠️
정보: 🔵 ℹ️ 💡 ❓
```

## 3. 타이포그래피

### 폰트 패밀리

#### 제목 (Headline)
- **Noto Sans KR - Bold (700)**
  - 크기: 24px (모바일), 28px (데스크톱)
  - 이유: 한글 표준, 친근함
  - 다운로드: https://fonts.google.com/noto/specimen/Noto+Sans+KR

#### 본문 (Body)
- **Noto Sans KR - Regular (400)**
  - 크기: 16px (크게! 초보자는 작은 글씨 못 읽음)
  - 줄높이: 1.6 (충분한 여백)
  - 이유: 친근, 가독성 최우선

#### 강조 (Emphasis)
- **Noto Sans KR - Bold (700)**
- 크기: 16px (같은 크기, 굵기로만 강조)

#### 숫자
- **Noto Sans KR - Bold (600/700)** 또는 **시스템 모노 폰트**
- 크기: 28px 이상 (점수, 수치 큼)
- 이유: 헷갈림 방지, 명확함

### 크기 체계

| 용도 | 크기 | 행높이 | 가중치 |
|------|------|--------|--------|
| 제목 (H1) | 28px | 1.3 | 700 |
| 섹션 (H2) | 24px | 1.3 | 700 |
| 카드 제목 (H3) | 20px | 1.4 | 700 |
| 본문 | 16px | 1.6 | 400 |
| 보조 텍스트 | 14px | 1.5 | 400 |
| 캡션 | 12px | 1.4 | 400 |
| 큰 숫자 (점수) | 48px | 1.0 | 700 |
| 중간 숫자 (값) | 32px | 1.0 | 700 |

### 타이포그래피 원칙
1. **모든 텍스트 16px 이상** (초보자, 고령자 고려)
2. **굵게 하기로 강조** (색상 변화 아님)
3. **전부 한글** (영문 약어도 가능하면 한글화)
   - 예: "EC 2.1 dS/m" → "전기전도도 2.1" (수치만 영문 유지)
4. **문장은 짧게** (15단어 이내)

## 4. 레이아웃 원칙

### 그리드 시스템
- **모바일 (320px ~ 540px)**: 2-column, 큰 여백 (16px)
- **태블릿 (541px ~ 1024px)**: 2-column 또는 3-column
- **데스크톱 (1025px+)**: 3-column

### 여백 시스템 (큼!)
```
8px, 12px, 16px, 24px, 32px, 48px, 64px
```

**강조**: 이 가이드라인은 **16px부터 시작** (일반적 8px 스케일보다 큼)
- 컴포넌트 내 여백: 16px
- 카드 간 여백: 24px (모바일), 32px (데스크톱)
- 섹션 간 여백: 32px ~ 48px
- 페이지 가장자리: 16px (모바일), 32px (데스크톱)

### 반응형 Breakpoint

| 기기 | 너비 | 특징 |
|------|------|------|
| 모바일 | 320px ~ 540px | 한손 조작, 큼 |
| 태블릿 | 541px ~ 1024px | 여유로운 배치 |
| 데스크톱 | 1025px+ | 정보 밀도 증가 |

### 모바일 우선 설계
1. **큰 터치 타겟**: 최소 56px × 56px (권장 64px)
2. **한 컬럼**: 모든 정보가 수직 스택
3. **하단 액션 존**: 중요한 버튼은 화면 아래 (엄지손가락 닿는 곳)
4. **가로 회전 지원**: 밭에서 각도 조정 가능하게

### 카드 구조 (명확한 시각 계층)
```
┌──────────────────────────────────┐
│                                  │
│  [큰 아이콘/이모지] 32px          │
│                                  │
│  제목 (H3, 20px, 굵음)           │
│                                  │
│  한 문장 설명 (16px, 일반)       │
│  (15단어 이내)                   │
│                                  │
│  [큰 행동 버튼]                  │
│                                  │
└──────────────────────────────────┘

모든 요소가 "위에서 아래로" 선형
좌우 복잡한 배치 금지
```

## 6. 음성 & 음향 지원

### 음성 가이드 (Voice Guide)
> 저문해율 사용자도 앱을 "이용"할 수 있게

1. **페이지 진입 시 자동 음성**:
   ```
   화면: "오이 적합도 카드"
   음성: "오늘 오이 재배 지표입니다. 안전함. 점수 85점입니다."
   (자동 재생, 끌 수 없음 아님)
   ```

2. **주요 버튼에 음성**:
   ```
   버튼: [오늘의 할 일 보기]
   누르기 전: "오늘의 추천 행동을 확인하세요"
   누른 후: "페이지를 불러오는 중입니다"
   ```

3. **경고 소리**:
   ```
   위험 신호 도착 시: 짧은 알림음 (1초)
   진동: 100ms, 100ms 쉼, 100ms (패턴)
   ```

### 자막 (Subtitle)
- 모든 음성은 화면에도 텍스트로 표시
- 음성만 의존하지 않도록 (WCAG 대응)

## 7. 인터랙션 & 애니메이션

### 원칙
> "느리고 명확한. 사용자가 '뭔가 일어났다'는 걸 느껴야 한다."

### 페이지 전환
- 슬라이드: 아래에서 위로 (400ms, ease-out)
- 느림 = 신뢰감 (빠른 애니메이션은 불안해 보임)

### 버튼 상호작용
- **누르기 전**: 기본 상태
- **누르는 중**: 배경 어두워짐 (즉시)
- **누른 후**: 리플 효과 (300ms) 또는 배경색 변화 (보존 0.5초)
- **완료**: 체크 마크 애니메이션 (팝 효과, 400ms)

### 로딩 상태
- **스케이톤 로더** (반복 펄스):
  ```
  배경색 #F0F0F0 ↔ #E0E0E0 (1.5초 반복)
  ```
- 회전 스피너 대신 **펄스** (보다 차분함)

### 데이터 업데이트
- 새로운 값 도착 시 **플래시** (1초 배경 하이라이트)
  ```
  배경: 흰색 → #C8E6C9 (연두) → 흰색 (1초)
  ```

### 스크롤 (조심스럽게)
- 기본 iOS/Android 모멘텀 (끄지 않음)
- 스크롤 시 헤더 축소 금지 (너무 복잡)

## 8. 접근성 고려사항

### 색상 대비 (WCAG AAA - 필수)
| 조합 | 대비율 | 준수 |
|------|--------|------|
| 안전 녹 (#4CAF50) + 흰색 | 6.4:1 | AAA |
| 주의 노랑 (#FDD835) + 검정 | 7.5:1 | AAA |
| 위험 빨강 (#F44336) + 흰색 | 5.2:1 | AA |
| 정보 파랑 (#2196F3) + 흰색 | 5.4:1 | AA |

**개선**: 위험/정보는 어두운 버전 검토
- 위험 다크: `#D32F2F` (7:1 달성)
- 정보 다크: `#1565C0` (7:1 달성)

### 색맹 대응 (필수)
- **절대 색상만으로 구분하지 않음**
- 항상 3가지 신호 병행:
  1. **색상** (녹/노랑/빨강)
  2. **기호** (✓/△/✗)
  3. **텍스트 라벨** (안전/주의/위험)

### 터치 타겟
- **최소 56px × 56px** (농촌, 고령자, 글러브 고려)
- 권장 **64px × 64px**
- 타겟 간 최소 **16px 여백** (실수 누르기 방지)

### 포커스 표시 (Keyboard)
```
포커스: 4px #4CAF50 테두리 + 4px 여백
모든 버튼, 입력 필드에 명확하게
```

### 화면 판독기
- **링크**: "오이 적합도 우수 자세히 보기"
- **이미지**: `alt="안전, 녹색 이모지, 85점"`
- **폼 라벨**: `<label for="crop-select">작물 선택</label>`
- **라이브 리전**: 새 경고 `aria-live="assertive"`
- **버튼**: `<button aria-label="오늘의 할 일 보기">`

### 글씨 크기 조정
- **기본 16px 이상** (이미 충분히 큼)
- 200% 줌 시에도 레이아웃 깨지지 않음

### 다크 모드
- 다크 모드에서 **명도 대비 AAA 유지**
- 예: 노랑은 다크 모드에서 더 어두운 황금으로

### 모션 감응증
```css

  /* 모든 애니메이션 즉시 또는 제거 */
```

## 9. UI UX Pro Max 활용 방안

### 1) 아이콘 세트 (큼, 명확)
- **Skill**: `ui-ux-pro-max:design` → "generate icon" (15가지 스타일)
- 스타일: **Duolingo 같은 컬러풀, 친근**
- 크기: 32px, 48px, 64px (크게!)
- 색상: 4가지 Semantic (녹/노랑/빨강/파랑)
- 심볼: ✓, △, ✗, ⚠️, 💡 등

### 2) 이모지 팩 (감정 전달)
- **Skill**: `ui-ux-pro-max:design` → 소셜 미디어 아이콘
- 상태별: 🟢🟡🔴 + 추가 이모지 (👍, ❗, 💧 등)
- 색상: 정확한 Semantic 매핑

### 3) 컴포넌트 라이브러리 (큼)
- **Skill**: `ui-ux-pro-max:ui-styling`
- Shadcn/UI 기반, 커스텀 크기 (56px+)
- 다크 모드, 접근성 자동 포함

### 4) 브랜드 (친근한 톤)
- **Skill**: `ui-ux-pro-max:brand`
- 로고 선택: "친근하고 온화한" 스타일
- 색상: 4가지 Semantic 강조
- 음성: "아이가 이해할 수 있는 간단한 한국어"

### 5) 음성 스크립트 (별도)
- 모든 페이지마다 음성 스크립트 작성
- 길이: 20초 이내
- 언어: 쉬운 한국어, 반복 최소화

## 11. 사용 시나리오 (흐름)

   ```
   화면: 대시보드 (큰 아이콘)

   ```

   ```
   큰 버튼: [오늘의 할 일 보기]
   ```
